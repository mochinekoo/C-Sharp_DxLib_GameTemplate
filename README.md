# 概要
* C#版DxLibのゲームで使えるテンプレートです。
* コードは、C++版を移植しています（ https://github.com/mochinekoo/C-PlusPlus_DxLib_GameTemplate ）。

# ライブラリ
* C#版DxLib： https://dxlib.xsrv.jp/dxdload.html

# クラス
* AppMain.cs：起動時のメインクラス
* Framework.cs ：テンプレートの固定の設定クラス。
* BaseScene.cs：シーンの親クラス。
* RootScene.cs ：一番最初の呼び出される、シーン。
* TestObject.cs：テスト用のオブジェクト
* SceneManager.cs：シーンを管理するクラス。
* Location.cs ： 場所を管理するクラス（DxLibにあるVECTORと大差ないと思います。）
